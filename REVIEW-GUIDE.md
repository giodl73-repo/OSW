# OSW — optional research review guide

Thank you for taking a look. This is a private, early-stage atlas preview, and
there is no expectation of endorsement, detailed review, or collaboration.
Brief reactions are useful; silence is also completely fine.

## A five-minute route

1. Open the [research note](research/) for the question, claims ledger, exact
   data receipt, and literature spine.
2. Open the [interactive Atlas](atlas/) and select one conceptual marker.
3. Switch once between **Observed SST** and **SST anomaly**.
4. If useful, open the [full annotated map](figures/osw-fluid-geography.svg).

## Questions that would help

Any one of these is enough:

1. Does the reservoir / pathway / anomaly / buried-layer / gate vocabulary
   clarify the physics, or does any category create a misleading mental model?
2. Is an important inferential boundary missing from the claims ledger?
3. Does the Drake Passage treatment fairly pair the idealized closure result
   with the evidence against gateway-only causation?
4. Which next layer would be most scientifically useful: depth-resolved Argo
   structure, bathymetry and sea ice, or dynamically consistent transport?
5. What would prevent you from citing, sharing, or using a future version?

## What this preview is not asking

- It is not asking the reader to validate the twelve schematic footprints.
- It is not asking for agreement with the HEATMASS terminology.
- It is not presenting a full-depth heat budget, causal attribution, or forecast.
- It is not requesting public association with the project.
