# RU29 2024: selected original source products

Data: Gradone, Joseph, *Mesoscale Variability and Water Mass Transport of the
Caribbean Current Revealed by High-Resolution Glider Observations*, Zenodo record 18332586,
https://doi.org/10.5281/zenodo.18332586. Licensed CC BY 4.0:
https://creativecommons.org/licenses/by/4.0/.
See `source-facts.json` for article and code attribution and exact locators.

These eleven files are unmodified NetCDF members of the provider's `data.zip`.
Local filenames are aliases: `custody.json` retains each exact original archive
member path, byte count, CRC32, SHA256 and compressed payload offset/hash.
The two interpolated occupations, complete processed velocity mission product,
and both rotations' tracked, untracked, short and correspondence products are
included. This is not all the archive's raw beam, hydrographic or satellite data.

Original archive URL:
https://zenodo.org/api/records/18332586/files/data.zip/content.
Only selected HTTP byte ranges were fetched. The 1.07 GB archive's published
MD5 has **not** been locally verified. Compressed payload ranges, source header
checks and selected member CRC32/SHA256 were verified; the retained range
receipts distinguish those checks from whole-archive verification.

`schema-inspection.json` is a metadata-only review snapshot; numeric attributes
are represented as strings there. The v1 producer retains attribute types and
all packed source cells separately, preserving default decoded masks. The
original NetCDF files are authoritative. No source packing, values, flags,
unit labels or category membership have been repaired.

Known source issues and interpretation limits are recorded in the prospective
protocol and `source-facts.json`, including missing current-variable units,
incorrect contour-latitude units, and the unresolved difference between the
paper's eddy filter description and commented author notebook code. These
products do not establish whole-current dimensions or seasonal envelopes.
