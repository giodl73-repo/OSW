# Public preview source use and bundle contract

The public preview must preserve all 111 current identities and their eligible evidence. The research snapshot remains intact. A separate, explicitly selected public bundle must enforce source-use decisions; it must not serve the working repository tree.

## Source decisions

[The current decision registry](../research/public-preview-source-use-decisions-v1.json) is bound to the audited display build. It distinguishes existing scoped approvals, attributed factual use, OSW-authored material, public-domain map data, and uses still requiring review. These decisions do not mark scientific claims reviewed or grant a licence to underlying articles and datasets.

The factual-use decision covers bibliography, attributed names, selected source-scoped numbers, and original OSW paraphrases. It excludes original articles, source media, publisher table assets, raw provider datasets, and provider geometries without their own approval. The [existing linked-facts policy](ocean-motion-linked-facts-use-decision.md) remains its basis. The actual display audit found only three quote-like fields: a three-word name, a five-word quote, and a review date; it found no packaged article or image asset.

Natural Earth explicitly permits use and modification of its map data in the public domain. Retain its credit and distinguish OSW's editorial ocean regions from current boundaries. [Natural Earth terms](https://www.naturalearthdata.com/about/terms-of-use/).

The [NWS reuse policy](https://www.weather.gov/disclaimer) has attribution, endorsement, and third-party qualifications. It is not a blanket clearance for Navy, CoastWatch, or other providers' records. The four explicit pending source IDs in the decision registry remain held until their particular uses are cleared.

## Identities and measurements

Keep all current IDs, source scopes, ranges, units, temporal qualifiers, and family or branch distinctions. Do not inherit member measurements into a parent, turn unknown into zero, combine incompatible length classes, or infer volume from unrelated dimensions.

The 96 Horizon registry labels remain excluded from the existing screened edition. Do not promote their publication status merely because a size reference was later associated with a research ID. Independently documented source cases may be considered separately, using the source's own name and scope, with an explicit decision. An unresolved name crosswalk remains unresolved. Do not copy registry separation dates into source event dates.

Retain qualifying eddy size references with their exact metric, definition, bounds, source locator, and identity status. A map-reading reference is not an observed physical radius or footprint. An evidence or case record is not automatically a new canonical eddy identity. Existing `rights_screened_release_eligible: false` values must not be silently flipped.

The [background citation supplement](../research/public-preview-source-supplement-v1.json) resolves the missing Orvik–Niiler metadata from retained custody evidence. It adds no new width observation and does not assert that contextual citations are independent corroboration.

## Geometry and links

OSW-authored locators and editorial routes retain their roles. Provider fronts, contours, field-diagnostic traces, and figure-derived outlines require field-specific source decisions. Do not grant geometry rights through a citation-only approval. Omitted geometry leaves the identity and permitted evidence available by name.

Source citations may link to primary publications without copying them. NASA movie navigation must retain NASA credits and model-visualization limits. A regional crop is not evidence that NASA identified the current or named eddy in that view.

Every public record reference must resolve to a permitted citation, a documented contextual citation, or an explicit unresolved status. The served package must contain no accidental routes into unreviewed research JSON, native archives, PDFs, private paths, or the full candidate dataset. Downloads and query results must use the same public edition as the map.

## Release evidence

The bundle build must record exact files and hashes, source decisions, retained and withheld scopes, identity and evidence counts, and a closed link and citation graph. Its checker must fail on pending provider values, prohibited assets, unresolved required provenance, or a missing current identity.

Browser review must exercise the actual bundle: first entry, current and source-case lookup, map/card navigation, source links, NASA navigation, query and downloads, deep-link reload and Back, keyboard focus, narrow layouts, and reduced motion. Keep scientific validation separate from usability and source-use checks.

Only after that concrete candidate is reviewable should the release version, public target, citation metadata, and owner promotion decision be reconciled. Preparation is authorized; this contract does not change Pages or `main`.

## Candidate metadata supplements and field screen

The exact candidate now has a separate [context citation supplement](../almanac/preview-review-v1/contexts.json) and [additional factual-use decisions](../almanac/preview-review-v1/source-use.json), bound to its build hash. The 30 context entries cite pinned OSW admission methods and recover retained primary bibliographic strings where available. An admission-method citation is not an independent measurement or a replacement for a reference's primary paper or data attribution. The 225 source-use decisions cover only the selected factual/OSW-authored material in this candidate, with the exclusions stated per URL. Original provider holds and original eligibility flags remain in force for their original scopes.

The metadata screen must preserve quantitative evidence as opaque bytes. It may decode an identity object's names, source IDs, and qualified state links to withhold unresolved observed-center/provider-polygon associations. It must prove every byte outside that object unchanged; it must not decode scientific numerical fields, rebuild measurements, infer dimensions, or promote source-case identity joins. The already checked Rust index is copied unchanged. Metadata/envelope JSON reads carry the compiled-query guard's existing numeric and byte charges; this is not a new scientific acquisition or a reset of that question's budget.

The scanner inspects JSON key names and bibliographic URL strings without decoding numerical evidence. Held provider URLs, prohibited original-asset fields, and unreviewed source URLs fail its gate. A metadata-screen pass alone does not certify scientific correctness, all primary citations, usability, or publication. Actual bundle validation and the release decision remain required.
