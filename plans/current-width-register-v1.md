# Width entries for every catalogued current

The target is a usable, sourced width entry for each of the111 catalogued
identities, with gaps explicit until supported. Reuse retained evidence first,
then fill missing current definitions. Work sequentially on one low-priority
CPU. Native/WASM builds, runtime packet/index parsing and browser automation
remain cloud-only. Keep one consolidated working branch and preserve the
completed length register and installed runtime.

The governing measurement rules are in
`plans/ocean-current-width-measurement-protocol-v1.md`. This register is a
presentation and gap-filling layer; it does not change scientific admission.

1. Retain every source record's identity, definition, location, vertical support,
   dates/season, source locator, boundary rule, provenance and caveats.
2. Keep point values, ranges and bounds separate. A range-only source has no
   invented midpoint. An order-of-magnitude or coastal-confinement description
   does not become a rigorous upper bound. Preserve strict inequalities.
   Preserve an explicitly reported zero endpoint in a source variability range;
   label it as reported, rather than using zero as a missing-data substitute or
   independently inferring current absence.
3. Distinguish a current width from one-sided distances, fixed-orientation
   section spans, water-mass cores, fitted scales, transport-integration spans
   and channel widths. These quantities cannot silently substitute for one
   another. A source's lack of a numerical cutoff remains explicit.
4. A local record is a local reference. Do not call it a whole-current typical
   width, buffer the entire length route with it, or calculate current area by
   multiplying it by the length register. A whole-current representative needs
   explicit spatial, vertical and temporal weighting with suitable coverage.
5. Preserve all alternatives rather than selecting a convenient record or
   pooling unlike definitions. Browse by current or definition; numeric ordering
   applies to one definition at a time and retains location/depth/period.
6. Keep seasonal pairs, sample spreads, source uncertainty, boundary sensitivity
   and along-route variation separate. Use only explicitly compatible seasonal
   groups. Multiple records or months alone do not establish annual extrema.
7. Families and networks retain member/passage-specific entries and explicit
   reference conventions. Do not add transverse widths or copy a member into
   a new physical measurement of its parent. Hypothesized connections and
   unresolved historical names remain qualified.
8. Deliver source-normalized JSON and CSV plus a lightweight width register,
   linked to source records, current cards, existing sample queries and length
   context. The overview must work without loading the large WASM packet.

Coverage counts separately report direct scoped evidence, family/member
references, unresolved contexts, and records capable of supporting a whole-
current representative. Do not equate these counts or call a context-only
record a filled physical-width gap.
