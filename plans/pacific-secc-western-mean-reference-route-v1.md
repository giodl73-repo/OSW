# Pacific SECC western mean reference reach

## Scope

Continue the existing reference-path convention: sourced schematic geography
can support declared OSW vertices, provided a regional reach is not promoted
to a whole-current length. Chen and Qiu (2004), paragraph2 and Figure1b,
identify the mean SECC in the western South Pacific and show positive mean
0-200m relative zonal geostrophy. Source reference pressure is1500dbar.
This is not an observed fixed-depth axis or an absolute velocity field.

## Declared path

Use an offshore164E gate and a near-dateline180E gate within this western mean
circulation context. Both are OSW truncations, not reported source endpoints.
Select connecting vertices near9-9.5S; no velocity maxima or contour boundaries
are extracted. The route excludes the western island/source branches, eastern
seasonal extensions, return SEC, STCC and subsurface equatorial jets.

Nominal, northern-bend and southern-bend drawings plus independent endpoint
latitude shifts of-0.25/0/+0.25degrees produce27 editorial scenarios. Longitude
gates stay fixed. Their length envelope measures sensitivity to these drawing
choices, not unresolved end-to-end naming scope, source errors, confidence,
seasonal variation, physical width or a bound on full-current length.

## Execution and admission

Freeze this protocol and input in Git before running the actual candidate.
Use the established reference-path generator, WGS84 shortest-leg sums and
periodic seam policy. Run geographic checks and mapping only in one sequenced
cloud case; no local land/state inventories, original velocity fields, full
packet or browser processing. Verify every scenario against the normal land
gate. Retain failures rather than removing failed scenarios silently.

Inspect the resulting route map before any query/atlas admission. The coarse
atlas land check is not fine-island, bathymetric or velocity continuity proof;
use the established finer mask gate where required for delivery. State/crop
joins remain editorial display context. Keep the separate published-length
ranking and annual ranges unchanged. Newer2026 Argo seasonal envelopes and
2004 anomaly sections are not inputs to this mean reference route.

Only after successful calculation, geography, visual and canonical-delivery
checks may reference-route coverage increase. The full physical current-length
