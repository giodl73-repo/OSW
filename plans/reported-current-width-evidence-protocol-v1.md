# Reported current width evidence, version1

This source-stage method applies the existing width and full-text prose
admission rules. It retains numeric source statements with their own region,
method, time support and access grade; it computes no current dimensions.

1. Pin the full original, acquisition receipt, source facts, prepared identity
   review, producer, synthetic tests and this protocol before actual execution.
   The original can remain locally ignored when redistribution is unlicensed.
2. Verify original bytes, digest, PDF page count, DOI and selected passage
   anchors. Selected-passage review is not a complete scientific paper review.
3. Preserve source widths as individual statements. A repeated abstract,
   summary, model comparison or broader discussion is not another independent
   observational sample. Mixed observation/model context must stay distinct.
4. Retain dates only at their declared precision and support. A transect
   window is not a timestamp for both edges. Do not copy cruise dates to
   narrower transects, contextual summaries or a different measurement method.
5. Use a numerical depth level only when the passage explicitly associates
   that level with its width description. Nearby speed/transport depth ranges
   do not become width layers. Unknown edge coordinates, cutoff and error
   remain null. No digitization or route reconstruction is performed.
6. Emit a report and original, accessible SVG with separate numeric markers,
   method/time labels, source links and unknown-error disclosure. Never join
   these markers into a footprint, seasonal envelope or confidence interval.
   Include broader/discordant statements visibly instead of averaging them.
7. Source-stage report creation admits no canonical identity, width sample,
   annual statistic, ranking, area, state join or physical animation. Existing
   measured quantities and executed products stay unchanged. Identity and
   canonical query/card/native/WASM delivery remain separate gates.
8. Freeze before first actual report/SVG generation; retain failures. Replay
   checks compare exact report and SVG bytes. Corrections require a new
   producer/protocol/source-facts version after execution.

First application: Wijesekera et al.2015, doi:10.1002/2015JC010744. T24
23-24December2013 is about100km wide at21m in section3.2. The same section
describes an approximately200km westward turn south of Sri Lanka in its
November-December observational context. Section4 gives250km south and west
in combined observational/model discussion. Their scope and support differ;
none defines an annual width range. The300km northward current is separate.
