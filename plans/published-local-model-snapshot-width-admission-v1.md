# Source-reported local model snapshot widths

Apply the existing width measurement protocol to a separately identified model
snapshot. Phase kind: `model_snapshot_width_summary`. Admit source-backed
approximate values as **scoped editorial evidence**, with all canonical-release,
whole-current, ranking, annual-extrema and seasonal-playback eligibility false.

Required support: stable current owner, original-source checksum and receipt,
passage and figure locator, model, experiment, elapsed model day, local section,
layer description, boundary rule, source precision and uncertainty status.
Missing paired coordinates, exact depth bounds or source errors remain null.
Model elapsed days cannot be converted into calendar dates. Annual climatological
forcing cannot become a measured annual mean or a seasonal width series.

source-defined value and experiment from the reviewed audit. Inventory projection
is an exact copy plus the audit address/checksum; no independent measurement is
created by this projection. The source audit now records editorial admission;
canonical-release admission remains false. Prior extraction-only status remains
available at commit `bce5dde`.

Count this as one scoped width record and one owner with scoped evidence, while
keeping whole-current width unknown. The existing HYCOM component-span diagnostic
remains separate. No numerical value, route, seasonal frame, extraction convention
or observation date from the existing155 records may change. Renew inventory
checksums and regenerate dependent object-scope counts, notes, diagrams and query
views. Any newly changed member counts are navigation to owned evidence, not
physical-width inheritance by a parent system.

Presentation must say **local model snapshot** next to the value. Display the
elapsed day and experiment, source limitations and direct source query. Hide the
illustrative geographic width bar; no inferred footprint or seasonal animation.
Reject changed values, source association, elapsed support, duplicated/erased
records and promotion to observed dates, annual means or annual ranges.
