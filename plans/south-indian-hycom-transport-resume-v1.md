# South Indian HYCOM transport resume v1

The first frozen acquisition pass retained 70 valid originals and encountered
12 socket timeouts. A second pass recovered additional originals, while some
identical URLs timed out again. This protocol changes a transport wait, not
the scientific sampling or arithmetic. Do not edit the frozen selection,
acquirer, shared parser, existing successful originals or their receipts.

After collecting the previous process's terminal result and confirming it
is no longer live, declare a bounded **180-second socket timeout** for the
remaining exact request URLs. Preserve the selection checksum, every existing
response and receipt checksum, missing-request list, helper/protocol checksums
and declaration UTC before sending those requests. Keep two simultaneous
workers, at most six selected dates per request and the original 20 MB response
cap. Use the unchanged response parser and exact coordinate validator.

Resume only the declared missing files. Validate an already completed pair
rather than replacing it. An incomplete pair requires inspection. Preserve
all failures; each new success records the declaration checksum and transport
timeout alongside its URL, original bytes, acquisition time and headers.
Afterward verify that every pre-existing successful original and receipt is
unchanged. Keep the declaration and helper dependencies with the retained
source archive and acquisition manifest, so the extended wait is reviewable.

No timeout failure becomes a missing ocean value or omitted date. No field,
depth, mask, grid, sample date, calendar threshold, numeric operation, encoding,
current identity, geometry or measurement-admission rule changes. Full-source
reconstruction and all existing numeric/byte checks remain required. This is
not a new dataset, a blind experiment or an admitted width.
