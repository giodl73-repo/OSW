# Kuroshio regional model dimensions: query/atlas contract v1

Extend the2024 source extraction on the same PR83. Preserve its daily outcomes,
original bytes, scope and historical release. One new collection,
`current_dimension_samples`, contains1098 regional-axis attempts and5490
fixed-latitude span attempts, including all unresolved cases. Unknown values
remain null. Keep date, source level/nominal depth, status, entity, source and
parent diagnostic queryable. Unknown numerical uncertainty remains null on every
row; boundary-fallback occurrence remains null on span rows, never false.
No row enters ranked lengths, canonical claims,
scoped widths, occupied areas or physical state passage.

IDs use source edition, calendar date, source depth level, metric/gates and
analysis version. They never use a filtered-array ordinal. Adding/reordering
years, levels or sections must preserve existing IDs. `report_case_index` is
only a pointer into one checksum-bound source snapshot, not persistent identity.

The compiled native/WASM validator binds the complete source report, input
checksums, source metadata, exact6588-row projection and Kuroshio owner link.
Reject changed values, missing cases, extra/unbound rows, date/depth changes,
rank promotion or erased provenance. Older snapshots without this edition
remain readable. Remove the source report's old live-interface flag: scientific
data should not carry stale UI status. Preserve every numerical case, frame,
summary and scope field; renew only the producer provenance. This separate
integration contract/version is authoritative for interface support.

Rust generates map paths from source vertices, breaking at nulls. Use the same
equirectangular projection and credited atlas coastline context. Do not buffer
lines or assign local spans to an entire current. Provide36 first-of-month
frames at the three declared depths. These are dated source snapshots, not
monthly means or a continuous trajectory. No interpolation or autoplay.
Explicit stepping may play only these dated frames; stop at year end, selection
change, hidden document, detached component and reduced-motion changes. Under
reduced motion keep manual date/depth controls and disable playback.

Expose the same map/table/source/query component from the global current atlas,
mapped current cards, seasonal page and exact diagnostic query. Model snapshot
month and nominal depth must remain visible. Distinguish selected-day rejected
measurements from gaps in displayed boundary curves. Show expected/valid counts
and separate regional/model sample ranges from error or physical annual extrema.
Retain the30% threshold/farthest-valid fallback caveat: censoring flags were not
published. A fixed-latitude span can exceed140km owing to obliquity.

Dashboard fingerprints should update only Kuroshio's new source/time/measurement
evidence. Catalogue identities, old lengths/widths/phase plans, all other owners
and state associations must remain unchanged. A new model-data capability is
presence of stored evidence, not confidence or scientific approval.

Verify complete native/WASM parity, deliberate corruption rejection, exact
source query, all6588 records and unresolved counts, keyboard controls,
320px reflow, reduced motion, map/card navigation and source-query sharing.
Measure the complete packet against Git's100MiB blob limit before publication.
Future years/levels need partitioned storage before the monolithic packet grows
