# Kuroshio axis-normal query/atlas integration v1

Bind all16,470 published attempts to an explicitly separate
current_axis_normal_samples collection. Preserve every existing regional-axis
and fixed-latitude record/ID, the licensed source record and all physical
inventories. New IDs come directly from the scientific source. Row ordinal
is only a snapshot-scoped source pointer. Unknown physical uncertainty,
threshold attainment and fallback occurrence remain null.

Native validation must pin source, figure receipt, all dependencies and the
typed contract, require exact projected rows/diagnostic and exactly one current
owner. New editions need a manifest flag; old snapshots without normal data
remain readable. Missing/changed/rebound rows, source links and geometry must
fail before querying. No partial normal edition is accepted.

Extend the existing shared model scene and component. Reuse date/depth
selectors, add metric and7/14/28km tangent controls, and preserve all selectors
in share links, map/card return and paired components. Render Rust-projected
geodesic normals, never occupied ribbons. Default existing views keep their
regional/fixed-latitude metric. Normal views display selected status, annual
and selected-month sample ranges/counts, method sensitivity and unknowns.
Keep every unresolved case queryable. Label tangent spread as method sensitivity,
not confidence; distinguish the geometric axis normal from velocity normal.

Register source/report/figure in source queries, normal records in main
queries, and one-owner dashboard measurement/time fingerprints. Preserve old
physical width/length ranks, observations, state passage and other owners.
Verify native/WASM parity, all attempts, source/row corruption rejection,
backward snapshots, source export, selector sharing/synchronization, keyboard,
320px reflow, reduced motion and global overlay clearing. Mainline coverage
is claimed only after the actual shipped UI passes these gates.
