## Fixed source and scope

Hansen etal(2011),doi:10.1029/2011JC007375, original13-page publication from
IFREMER Archimer item16771/file14216. The acquisition receipt fixes its SHA256
and byte count. The copyrighted PDF and rendered pages remain ignored.
Publish only factual paraphrases, scalar values and an independent figure.

Paragraph9 and Figure2 define the ASAR mean as August2007-July2010. This
overrides neither the broader2007-2011 collection period nor individual scene
dates. It supplies no seasonal series. These are widths of a weighted mean
surface range-Doppler field, not means of instantaneous widths. A5km output
grid is distinct from10km spatial resolution. Velocity RMSE is not width error.

Paragraph10 reports60km FWHM at P1(62N,0deg30minW). Admit this local NwASC
surface-profile description. Preserve the projected Doppler operator; do not
call it a flow-normal in-situ width or infer geographic edges.

The45km P2(62deg40minN,3E) value occurs where the signal aligns with the NCC.
Retain it as possibly mixed context, excluded from separate-current widths.
The60km S1(62deg48minN,4deg15minE) profile explicitly combines NwASC and NCC:
retain as mixed context. Neither value is an independent NwASC measurement.

At S1 the authors use the200m isobath to partition the signals and report36km
for NwASC. Admit a separate conditional partition estimate. The isobath is a
bathymetric separation assumption, not a sampling depth or measured interface.
Do not subtract36from60 to invent an NCC width. The partition value is not
equivalent to the unpartitioned FWHM and carries no reported numeric error.

Paragraph12 reports an approximately30km NCC surface jet near64N,9E, between
Haltenbanken and Froya. Admit a local NCC description; its width operator is
not explicitly restated as FWHM, so retain that uncertainty. The position is
approximate. No value transfers to the ambiguous Norwegian Current family.
