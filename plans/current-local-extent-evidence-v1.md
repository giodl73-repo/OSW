# Current local extent evidence: data contract v1

Purpose: retain queryable model-section dimensions recovered by a diagnostic
without promoting them to admitted physical current widths. This contract first
covers the executed EACC HYCOM2013 case. It neither repeats its numerical
calculation nor changes its83 frozen source inputs.

## Separate collections and ownership

`current_local_extent_cases` holds all72 original case identities, model month,
normal sampling step, neighboring native-latitude offset, adapter audit and
unchanged regional gates. `current_local_extents` holds all864 attempted
case/fraction/quantity slots. Unsupported attempts remain records with their
exact status and null bracket where the original report has no bracket.

`investigated_current_id` identifies the catalog target of this investigation;
it does not certify a physical current polygon or independently attributed
boundary. These collections do not add `width_ids`, width samples, measurements,
routes, physical geometry, length/width ranks, annual ranges or OSW state joins.
Current-wide coverage counters must not treat these rows as complete widths.

The four controlled quantity names remain:

1. `core_to_positive_normal_threshold_extent`
2. `local_two_sided_threshold_span`
3. `finite_paired_support_to_positive_threshold_extent`
4. `shore_reference_to_positive_threshold_extent`

Do not pool quantities, double a one-sided extent, supply a midpoint or discard
failed primary cases in favor of successful sensitivities. The positive normal
remains a signed coordinate, not a verified geographic offshore direction.

annual envelope or replace missing slots with zero. Label2013/15m/monthly means,

## Serial verification and delivery

First write the adapter and tiny synthetic checks. Then run one focused command
on one BelowNormal CPU with one numerical worker. Separately verify/copy the
already retained compact scalar report, then render the small primary-month
chart with a standard plotting tool and inspect it. Preserve every executed
input and source byte. No local source arrays, full index loads, native/WASM
builds, browser automation or bulk synchronization are required at this stage.

The resulting research bundle is a candidate for explicit query integration.
Actual Rust/query registration, owner references, catalog indexing and UI
delivery require their own verified source changes and serial cloud checks.
Do not claim the installed atlas contains this new collection before that work
has been completed. Physical current-width admission remains a separate gate.
