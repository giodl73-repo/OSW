# Algerian regional width convention v1

2026-10-08. Supplement to unchanged general width protocol v1.21.
Retain the original-reviewed 30-50 km along-slope regional current description
from Cotroneo et al. (2019), section 1, printed p148. Use existing
`regional_summary`, `published_regional_summary` and
`author_reported_current_width` conventions; no new physical width definition.

Keep the reported span with a null scalar; no 40 km midpoint. The introductory
regional synthesis is not a dated ABACUS width observation, three autumn widths
or annual extrema. Autumn 2014-2016 missions, 0-975 m sampling and variable
surface profile spacing describe the dataset, not the width's time/depth support.
No fixed layer, threshold, exact occupations, calendar or geographic edges supplied.
Neighboring Levantine Intermediate Water depth is not a width layer. Detached
eddy diameters are separate metrics and do not widen this named current.

The source cites Testor et al. (2005); underlying original width methods remain
unreviewed. Preserve this citation lineage without counting it as independent
corroboration. Full-width/rank/seasonal-playback/annual-extrema flags remain false.
Show the span schematically beside its regional synthesis label and unknown
numerical uncertainty. No width bar, route buffer, annual animation or state
footprint inferred. Bind complete row to original/acquisition/protocol/audit
receipts in Python and Rust. Resolve paired boundaries and compatible repeats
before geographical or monthly/annual admission. Independent scientific review
remains pending. Publisher PDF is CC BY 4.0 and retained with attribution.
