# One compatible Loop Current cloud delivery case

## Prepared case

`analysis/check_loop_published_metrics_delivery_v1.py` is a cloud-only runner.
The workflow has one job, under the shared serial lock. The initial request is
disabled. It preserves the global scientific source-processing hold and checks
all earlier applicable requests are disabled. GitHub contents permission is
read-only, so this case cannot install or merge its generated files.

The source gate binds the exact source/remote head and clean checkout, parent
packet, 98 Rust/Cargo files, 144 compiled-data inputs, matching installed engine
and all inherited source freezes. Local invocation is rejected before reading
any source, payload or binary. All execution uses one actual CPU, reduced
priority and single-worker settings. No original velocity fields are acquired
or processed; no local full packet/index or compiled binary is opened.

## Ordered execution

1. Verify the installed South Java parent and each packet part. Apply the exact
   fourteen-row scalar contract transactionally, with explicit source reuse or
   collision refusal. Preserve every old row, scientific field and observation
   date; update the Loop evidence references and dashboard projection only.
2. Extend the lossless source index by the four declared JSON documents and
   dashboard replacement. Check all 597 original strings, preserving 596 and
   replacing only the dashboard; require 601 resulting indexed sources. Serialize
   a saved derived candidate without replaying historical producers.
3. Compile a native CLI followed by one WASM engine. The only allowed compiled
   data change is the new index catalog; all reviewed Rust sources stay exact.
   Verify compiler-emitted dependencies and actual data hashes.
4. Compare eleven complete main-store responses, including exact new rows,
   explicit null-versus-zero queries, publication/method sources, both November
   events, the Loop owner, normal 106-current inventory and old South Java depth
   context. Compare nineteen source-store responses: four documents, fourteen
   exact source pointers and one old source. Initialization metadata must also
   match. Both native and WASM must reject a mismatched source corpus.
5. Save the verified derived files and matching engine in a cloud artifact
   folder, with their hashes, before browser work. If browser review fails,
   retain this partial evidence as such; do not claim approval or installation.
6. After native/Node processes finish, run one browser review. Check keyboard
   dashboard navigation, generic values and scope notes, publication-link
   destination, complete collections and both November dates, exact indexed
   documents, the static page/chart and 320/390px reflow. Save selected PNGs.
7. Retain compact evidence and the derived artifact only in the cloud. Disable
   the request once the observed run is terminal. Actual visual review of the
   saved screenshots and exact-artifact installation are later serial steps.

The source page's detailed chart uses its full-size link and matching tables;
phone readability of every chart label is not implied. Browser checks do not
claim the external publisher website was loaded successfully; they verify the
reviewed publication link. No external PDF/ZIP/netCDF/NPZ download is permitted
in normal page use.

## Local preparation evidence

passed in 0.102s. They ran sequentially on one BelowNormal CPU. The seventeen
query/source/formatter checks were already verified in the preceding frozen
preparation; the initial delivery test discovery also ran those seventeen while
checking fixture reuse. Imported test-class discovery was then removed so the
delivery suite now runs only its seven distinct tests. No local compiler,

## Release limits

The case cannot add ranked whole-current lengths, widths, annual extrema,
uncertainty margins, eddy names/tracks, state intersections or NASA matches.
It structures published contour statistics and a partial final-separation event
list. A PASS without actual screenshot review still has visual approval pending.
Use the existing branch/PR; no per-gap PR, main merge or scientific release.
