# Field Guide to Ocean Objects

The ocean is not empty blue space. It contains recognizable structures—but
different structures answer different questions. This guide teaches how to see
them, measure them, and avoid confusing one kind for another.

## How to read these guides

The diagrams are explanatory schematics, not measured maps. Their surrounding
prose is the canonical text alternative: no conclusion depends on recognizing
colour, line art, or spatial alignment alone. Quantitative **OSW examples** link
to their figure or receipt; outside examples link to literature or the source
register. A named object remains a candidate until it passes the detection tests
declared in its guide.

Claim-stage labels used throughout the collection:

| Label | Meaning |
|---|---|
| Concept | explanatory definition or schematic, not a detected feature |
| Reference geography | a declared indexing system, not a material boundary |
| Field | a measured or derived variable on declared space and time support |
| Detected state | an object produced by a stated field, scale, time, and rule |
| Integrated quantity | a section, surface, or volume integral with geometry, signs, units, and provenance |
| Mechanism hypothesis | a causal explanation or analogy with a stated falsification test |

Claim stage does not identify evidence origin. Receipts separately label
observational analysis, assimilative reanalysis, simulation, or conceptual
synthesis; an integrated quantity can come from any suitable source.

For the formal type × identity-test system behind these chapters, open
[Classifying Ocean Objects](../CLASSIFICATION.md) and its
[116-term registry](../research/ocean-object-classification.csv). The companion
[relationship registry](../research/ocean-object-relations.csv) records how
objects carry, bound, transform, steer, overlap, and measure one another.

## Start with the object families

| Family | The question it answers | Objects |
|---|---|---|
| Property | What kind of water is here? | water masses, mixed layers, thermoclines |
| Boundary | Where does the water change sharply? | fronts, haloclines, pycnoclines |
| Motion | How is it moving? | currents, jets, bands, eddies, filaments |
| Transport | What crosses this line? | gates, branches, volume transport, heat transport |
| Transformation | How does water become another kind? | surface forcing, mixing, formation, overturning |
| Connectivity | What stays together or exchanges? | coherent sets, barriers, pathways, recirculations |
| Geography | How can the ocean be exhaustively indexed? | basins, Longhurst provinces, dynamic seascapes |
| Event | What unusual condition is happening now? | marine heatwaves, cold spells, blooms |

## One parcel, several objects

```text
ONE PARCEL OF ATLANTIC WATER
│
├── has properties ───────► Atlantic Water mass
├── sits in a layer ──────► upper-ocean Atlantic layer
├── moves in a core ──────► Norwegian Atlantic Current jet
├── crosses a section ────► Iceland–Scotland transport gate
├── occupies geography ───► a Nordic basin and ecological province
├── may enter an event ───► a marine heatwave anomaly
└── may transform ────────► colder, fresher, denser outflow water
```

These labels overlap because they describe different relations. A state-like
partition can cover the whole ocean only after declaring one rule: ecology,
water properties, drainage/connectivity, or another chosen variable. It cannot
replace all other object systems.

## The OSW object card

Every mature guide should answer the same questions:

```text
Definition     What makes the object exist?
Boundary       How is its edge detected?
Dimension      Point, line, surface, volume, pathway, or event?
Lifetime       Instantaneous, seasonal, persistent, or climatic reference?
Measurement    Which observations or model fields reveal it?
Transport      Does it carry water, heat, salt, organisms, or nothing by itself?
Scale          At what resolution does it split or merge?
Counterexample What looks similar but fails the definition?
Status         Reference geography, detected state, hypothesis, or measured flux?
```

## A rule for naming

Name an object only after specifying its test. “Warm blob” is an observation.
“Atlantic Water” requires a property definition. “Jet” requires velocity
structure. “Heat transport” requires temperature, normal velocity, and section
geometry. “Coherent region” requires a time interval and a transport/coherence
criterion.

## Research position

OSW did not discover these object classes. Physical oceanography already studies
fronts, jets, eddies, water masses, transformation, and coherent transport; ocean
ecology already uses exhaustive provinces and dynamic seascapes. OSW's working
contribution is to place them in one public visual grammar with explicit tests,
scale declarations, receipts, and cross-links.
