    What this exchange earns—and what it does not

    All native-grid, sign, units, partial-cell thickness, tracer-collocation, missing-value, matched-control, and closure-scope checks pass for this bounded pilot. Volume reverses sign across the four sampled months; reference-relative thermal transport at 0 °C does not. The displaced control has the same broad seasonal sign pattern, so the result does not establish a uniquely organizing material boundary.

    Only 16 of 18 native source-edge faces are measured. This is one ORAS5 member, one year, and one product; second-product sensitivity, observations, submonthly covariance, full-edge transport, convergence, climatology, and zoning remain unsupported.
